# Engineering Notes

Engineering Notes are where learning starts. Each note records how something works, what was tried and what broke along the way. That way the next build starts from experience instead of a blank page.

Notes are the first step on the path from **learning** to **product**. A note that proves useful often grows into a hands-on tutorial. Later it may become a [Self-Hosting Guide](../self-hosting/index.md).
