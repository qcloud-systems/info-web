# Self-Hosting Guides

Self-Hosting Guides are for **administrators**. Engineering Notes explain *why* something works. These guides cover *how* to run it reliably on your own server: install, secure, deploy, monitor and recover.

!!! tip "Suggested order"
    New to self-hosting? Read [Linux](linux/index.md), then [Docker](docker/index.md). Next comes [Cloudflare](cloudflare/index.md) to put a service on the internet safely. Finish with [Deployments](deployments/index.md) and [Monitoring](monitoring/index.md).
