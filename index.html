Frequently Asked Questions

Where are incidents and planned maintenance announced?

On the Notices page, which also has an RSS feed you can subscribe to.

Is the status section a status page for QCS services?

No. It reports only on the third-party platforms QCS projects depend on, read from each provider's own status feed.

Does this site track visitors?

No. It sets no cookies and runs no analytics or tracking scripts. The Privacy Policy explains the little information that is involved in serving a website.

How do I report a security vulnerability?

Please report it privately — not in a public issue. The Security Policy explains how.

How is this site built?

It is a small Go program that renders static pages at build time. How It's Built walks through every part of it.

How can I suggest a correction or improvement to this site?

Open an issue on GitHub, or see the Contributing Guidelines.

Contact

For questions about QCS services, these policies, or a notice, reach us on GitHub or Medium. Security issues should be reported privately, as described in the Security Policy.
